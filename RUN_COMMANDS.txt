================================================================================
VIDEO LECTURE TRANSCRIPT QA BOT - RUN COMMANDS
================================================================================

Run these from the project root: D:\video-lecture-transcript-qa-bot

--------------------------------------------------------------------------------
OPTION 1 - MANUAL RUN (4 separate terminals)
--------------------------------------------------------------------------------

TERMINAL 1 - Backend API (port 8000)
  cd .\backend
  .\.venv\Scripts\Activate.ps1
  .\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

TERMINAL 2 - RAG Service (port 8100)
  cd D:\video-lecture-transcript-qa-bot
  .\rag\.venv\Scripts\Activate.ps1
  .\rag\.venv\Scripts\python.exe -m uvicorn rag.app:app --host 127.0.0.1 --port 8100 --reload

TERMINAL 3 - Frontend (port 5173)
  cd .\frontend
  npm run dev

TERMINAL 4 - Load testing (Locust)
  cd .\load_tests
  ..\.venv\Scripts\python.exe -m locust -f locustfile.py --host http://localhost:8000 --users 10 --spawn-rate 2 --run-time 1m

--------------------------------------------------------------------------------
OPTION 2 - ONE CLICK (PowerShell)
--------------------------------------------------------------------------------

From project root:
  .\run-services.ps1

Or from Explorer:
  .\run-services.bat

--------------------------------------------------------------------------------
FIRST TIME SETUP (run once)
--------------------------------------------------------------------------------

1) PostgreSQL must be running with database: video_lecture_transcript

2) Backend setup:
  cd .\backend
  python -m venv .venv
  .\.venv\Scripts\Activate.ps1
  pip install -r requirements.txt
  .\.venv\Scripts\python.exe create_db.py

3) RAG setup:
  cd .\rag
  python -m venv .venv
  .\.venv\Scripts\Activate.ps1
  pip install -r requirements.txt

4) Frontend setup:
  cd .\frontend
  npm install

5) Install Locust:
  cd .\
  .\.venv\Scripts\python.exe -m pip install locust

6) Install ffmpeg (required for Whisper):
  winget install Gyan.FFmpeg

--------------------------------------------------------------------------------
OPEN IN BROWSER
--------------------------------------------------------------------------------

  Main App:       http://localhost:5173
  Backend Docs:   http://localhost:8000/docs
  RAG Docs:       http://localhost:8100/docs
  ChromaDB UI:    http://localhost:8100/viewer

--------------------------------------------------------------------------------
USEFUL COMMANDS
--------------------------------------------------------------------------------

Ingest video from command line:
  cd .\rag
  .\.venv\Scripts\python.exe -m rag.ingest "C:\path\to\video.mp4" --title "Lecture 1"

Ask question from command line:
  cd .\rag
  .\.venv\Scripts\python.exe -m rag.query "What is this lecture about?"

Run load test with HTML report:
  cd .\load_tests
  ..\.venv\Scripts\python.exe -m locust -f locustfile.py --host http://localhost:8000 --users 50 --spawn-rate 5 --run-time 5m --html reports\report.html
