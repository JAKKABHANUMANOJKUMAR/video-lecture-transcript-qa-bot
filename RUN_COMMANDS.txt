--------------------------------------------------------------------------------
FIRST TIME SETUP (run once)
--------------------------------------------------------------------------------

1) PostgreSQL must be running (database: video_lecture_transcript)

2) Backend setup:
  cd backend
  python -m venv .venv
  .\.venv\Scripts\Activate.ps1
  pip install -r requirements.txt
  python create_db.py
  copy .env.example .env
  (edit .env with your PostgreSQL password)

3) RAG setup:
  cd rag
  python -m venv .venv
  .\.venv\Scripts\Activate.ps1
  pip install -r requirements.txt
  copy .env.example .env
  (edit .env - add GROQ_API_KEY and PostgreSQL password)

4) Frontend setup:
  cd frontend
  npm install
  copy .env.example .env   (if exists, or use frontend\.env)

5) Install ffmpeg (required for Whisper):
  winget install Gyan.FFmpeg

--------------------------------------------------------------------------------
OPTION 3 - DOCKER (all services in one command)
--------------------------------------------------------------------------------

  copy .env.docker.example .env.docker
  (edit .env.docker - set GROQ_API_KEY, passwords, PUBLIC_ORIGIN)

  docker compose --env-file .env.docker up -d --build

  Open: http://localhost
